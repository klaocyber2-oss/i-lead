# I-LEAD — ต้นแบบระบบ (Mock-up)

ต้นแบบหน้าจอระบบสืบสวนและข่าวกรอง I-LEAD เพื่อประกอบข้อเสนอโครงการ

> **ข้อมูลทั้งหมดในต้นแบบนี้เป็นข้อมูลจำลอง** ชื่อบุคคล คดี สถานที่ เลขเอกสาร และตัวเลขสถิติทั้งหมดสร้างขึ้นเพื่อการนำเสนอเท่านั้น ไม่ใช่ข้อมูลจริงและไม่ใช่ระบบจริงของหน่วยงานใด

- เปิดดูออนไลน์ผ่าน GitHub Pages ของ repository นี้
- กด "เข้าสู่ระบบ" ได้โดยไม่ต้องใส่รหัสผ่าน และเลือกบัญชีทดลองตามบทบาทเพื่อดูสิทธิ์ที่ต่างกัน
- ไลบรารีที่ใช้ : SheetJS, html2canvas, jsPDF (ส่งออกไฟล์) และฟอนต์ Prompt / Sarabun (SIL Open Font License)
